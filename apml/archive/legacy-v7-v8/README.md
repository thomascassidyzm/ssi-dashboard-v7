# Legacy APML v7.x and v8.x Files

**Archived:** 2026-01-12
**Status:** DEPRECATED - Historical Reference Only

## Purpose

These files document the evolution of APML from v7.0 through v8.1.
They are preserved for historical reference but have been superseded
by APML v9.0+ and APML v2.1.0 specification.
