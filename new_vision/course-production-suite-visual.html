Course Production Suite

Integrated QA, Recording & Audio Pipeline Architecture

System Overview

📄
Script Viewer
QA Tool for reviewing entire course scripts with Descript-style browsing
  • Flag items for editing
  • Audio regeneration controls
  • Filter flagged items
  • Deep linking support
⚙️
Audio Pipeline
TTS batch generation and monitoring system
  • Queue management
  • Real-time progress
  • Retry failed samples
  • Preview & approve
🎤
Recording Studio
Autocue system for manual voice recording
  • Phrase grouping
  • Slow-with-gaps mode
  • Queue-based workflow
  • S3 upload integration
🔊
Samples Browser
Quality review interface for all audio
  • Grid/list views
  • Compare TTS vs Human
  • Approve/reject workflow
  • Bulk operations

API Endpoint Structure

/api/production/:courseCode
  ├─ GET  /manifest              → Load course manifest
  ├─ GET  /flags                 → Load sample_flags.json
  ├─ POST /flags/update          → Update flag status
  ├─ GET  /audio-metadata        → Load audio metadata
  └─ POST /audio-metadata/update → Update audio info

/api/production/:courseCode/script
  ├─ GET  /seeds                 → Load all seeds
  ├─ GET  /seeds/:seedId         → Load specific seed
  └─ GET  /samples               → Load filtered samples

/api/production/:courseCode/audio-pipeline
  ├─ GET  /status                → Pipeline status
  ├─ POST /queue/add             → Add to TTS queue
  ├─ POST /queue/retry           → Retry failed
  └─ GET  /queue/history         → Generation history

/api/production/:courseCode/recording
  ├─ GET  /queues                → List recording queues
  ├─ POST /queues/create         → Create new queue
  ├─ POST /upload                → Upload recorded audio
  └─ POST /complete              → Mark complete

/api/production/:courseCode/samples
  ├─ GET  /list                  → List all samples
  ├─ GET  /:uuid                 → Get sample details
  ├─ POST /:uuid/approve         → Approve sample
  ├─ POST /:uuid/reject          → Reject sample
  └─ POST /:uuid/compare         → Compare TTS vs Human

/api/production/websocket      → Real-time updates
