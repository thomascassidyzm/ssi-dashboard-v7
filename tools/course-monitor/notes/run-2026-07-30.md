## How to re-derive the seed counts
```
ssh ssi@apidev 'bash -lc "cd ~/course-materials/course-configs/Courses; \
  python3 -c \"import json;d=json.load(open('en-es.json'));\
  print(d['version'], len(d['slices'][0]['seeds']), len(d['slices'][0]['pooledEncouragements']))\""'
```
`slices[0].seeds` = deployed seed count; `slices[0].pooledEncouragements` = enc set size.
