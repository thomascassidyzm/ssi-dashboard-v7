## Overall Recommendations

### Chunk-First Approach Benefits

1. **Reduced Cognitive Load**: Teaching "I want to" as a chunk reduces working memory demands
2. **Natural Fluency**: Learners acquire language patterns as native speakers use them
3. **Faster Phrase Building**: Pre-assembled chunks mean fewer assembly steps
4. **Better Retention**: Meaningful chunks are easier to remember than isolated words

### Implementation Strategy

1. **Priority 1**: Add frequent bigrams/trigrams (10+ occurrences) as M-LEGOs
2. **Priority 2**: Fill missing intermediates (A exists, A+B+C exists, add A+B)
3. **Priority 3**: Add language-specific collocations based on linguistic patterns
4. **Priority 4**: Create overlapping variants for high-usage LEGOs

### Next Steps

1. Review top 20 frequent patterns per language with linguistic experts
2. Validate missing intermediates against pedagogical requirements
3. Design chunk LEGOs with proper component structure
4. Update Course Builder API to handle chunk LEGOs efficiently
5. Test chunk-first approach with pilot course sections
