## P2 — More than 500 identical silent slots cannot be filled

**Location:** `tools/course-optimization/fill-silent-phrases-since.cjs:66`.

**Concrete input:** 501 selected practice-phrase rows in one course, each with `known_text: 'Hello'`, `known_audio_id: null`, and filled target audio slots. `RENDER=1`; both render calls return HTTP 200 with `{ ok: true, source: 'library', audioId: '<valid existing UUID>' }`.

`asks()` groups all 501 ids into one `(known, Hello)` ask. The added request sends all 501 links together. `services/shared/link-clip.cjs` rejects any array longer than 500 with `TOO_MANY` before reading or writing any slot; `services/production-api.cjs:3860` maps that to HTTP 400. Consequently none of the 501 slots gets filled. Running the tool again produces the same oversized request. This also affects a newly rendered clip, leaving it stored but unattached to these phrases.

**Smallest fix:** split each ask's ids into batches of at most 500 and send the same returned audioId with each batch, accumulating the linked count.
