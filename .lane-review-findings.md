## 1. P2 — component words disappear from v4's heard-word fallback

Location: `services/course-builder/lib/phrase-generation-v4.cjs:92`.

Its `extraCheck` later passes this object to the real `gateStagedRows`, whose no-pair-contract fallback reads components exclusively from `data.phrases`. Consequently words taught only by components are reported as unheard, blocking otherwise acceptable baskets and burning generation retries. The gap-fill landing door retains these rows, so generation and landing disagree.

It proves this branch's data-loss defect; it does not claim the deliberately minimal candidate passes all other production gates.

## 2. P2 — 25 refused voice slots silently discard the valid remainder

Location: `tools/frame-layer/v4/voice-gap-fill.cjs:107` (silent return at line 122).

`linkChunk` removes one refused op per iteration, but caps iterations at 25 although its caller supplies chunks of up to 200. After 25 refusals it returns success-shaped output without applying or recording the remaining ops as skipped. The caller advances to the next chunk and prints DONE, leaving already rendered clips unattached.

Concrete input: 26 rendered known-slot ops; preview returns indexed DRIFT for the first 25, one at a time, while the final op is valid. Actual result is `applied:0`, `skipped.length:25`, no apply call; the final valid slot disappears from the accounting. With a 200-op chunk, up to 175 valid slots are abandoned.

Smallest fix: replace the bounded loop with `while (live.length)`. Every caught recoverable refusal removes an op; every other error throws; a successful preview applies and returns, so this already terminates.
