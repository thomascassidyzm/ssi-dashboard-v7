# Japanese Target-Centred LEGO Build: Layer 0 (Meta)

*Experimental build following target-centred principles - January 2026*

---

## Principles Applied

1. **Target-first** - Japanese forms chosen first, back-translated to English
2. **Master keys** - One Japanese form covers multiple English meanings
3. **Grammar baked in** - Particles and conjugations embedded, not taught separately
4. **Colloquial** - Casual forms, lowest cognitive load
5. **Understandable** - Native speakers will understand (not necessarily "textbook correct")
6. **Layer 0 focus** - Meta conversation about learning itself

### Communicative Capabilities After 30 LEGOs

The learner can express:
- **Intent**: want to speak, practice, listen, learn, try hard, become better
- **Difficulty**: hard, a little hard, still hard, but okay
- **Attitude to mistakes**: even if I make mistakes, it's okay/fun
- **Requests**: slowly, one more time, teach me, please
- **Degree**: a little, more, still, every day, little by little
- **Medium**: in Japanese
- **Ability**: can, can't yet, can do a little
- **Skill level**: good at, not good yet, want to become better
- **Emotions**: fun, happy, okay
- **Questions**: what, how, what is this in Japanese

## Notes for Review

1. **Particle dropping**: Casual Japanese drops particles freely. All phrases are understandable without explicit を, が, etc.

2. **Word order flexibility**: Casual Japanese has flexible word order. Phrases prioritize naturalness over textbook correctness.

3. **No loanwords yet**: Layer 0 (meta conversation) doesn't naturally use loanwords. Layer 1 (basic needs) would introduce コーヒー, ビール, etc.

4. **Verb form consistency**: All desire verbs use ～たい form (want to X). This is the casual pattern.

5. **Cultural note**: 頑張りたい introduces a uniquely Japanese concept with no English equivalent - a "cultural master key."
