## Note on `explain`

`to explain → a mhíniú` is already live at S8.3. This band introduces the **bare** verbal noun
`míniú` glossed simply `explain`, because seed 211's own sentence
(`… ag iarraidh míniú`) has no `a`-particle and the 8-syllable LEGO cap forbids folding it into a
larger tile. The two are the same word in different syntactic positions, and the course already
does exactly this elsewhere (`foghlaim` / `a fhoghlaim`, `labhairt` / `a labhairt`). Flagged here so
a ZUT sweep can see it was deliberate rather than a divergence.
