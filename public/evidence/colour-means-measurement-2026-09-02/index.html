Colour means measurement

Acceptance evidence for Tom's ruling of 2026-09-02. Three screens, two widths, both themes.

This is a harness, and it says so. Every photograph was taken by a real Chromium signing in through the real login form as the seeded E2E admin, against the real production-api on port 3470 and the real canonical store. Auth is not stubbed and no row is faked. Every request the harness makes is a GET; it writes nothing and spends nothing. Source: e2e/colour-rule/shots.spec.js.

Alongside the photographs, the harness asserts the rule itself: it walks every rendered element on each page, reads its computed colour, border, background, fill and stroke, and fails if any of them lands in the red or amber families. One exemption, named in the code: the Environment Switcher's connection dot, which is a fault light rather than a measurement — the same place /courses, the reference implementation, keeps red.

Script Lab — no language selected

Canonical only, at full width, with the LANGUAGE chip row that used to be missing. KNOWN and TARGET are gone because with nothing selected they carried zero bits — a byte-identical copy and a column of em-dashes.

Script Lab — a language selected

Pick ita and the three columns come back, all three now worth their width: canonical, known, and 276 lines of real Italian.

Script Lab — a script with no language layer

pod-1 carries no target language at all, so the chip row says so in a sentence rather than offering a dead control.

The metagraph card grid

18 reached shapes are solid, filled and full opacity with their ×n counts. 18 never-reached shapes are dashed, unfilled and dimmed. No red anywhere, and the deficit list under the count is plain grey body text.

What changed, in one line each

  • Absence is drawn, not coloured. Reached = solid outline, filled, full opacity. Never reached = dashed, unfilled, dimmed, ink text. Three redundant channels.
  • Red is gone from both screens except one fault light.
  • Headings, breadcrumbs, node ids, the active nav tab, the chunk-mapping chip, the course-code chip and the build sha are ink and grey.
  • Blue is the single action colour — the Save button now wears it.
  • Script Lab is canonical-only at full width until a language is picked, from a chip row lifted off the Metagraph.
  • The Library's type scale is now a named token set, adopted rather than re-tuned per screen.
