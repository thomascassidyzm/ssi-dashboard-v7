# SSi Learner Pattern

What the learner experiences. Understand this to build courses correctly.

## The Learning Journey

Each LEGO introduction follows this pattern:

```
ROUND N - Introducing LEGO "I'm trying" → "dw i'n trio"

1. INTRO: Hear the new LEGO
   I'm trying → dw i'n trio

2. LEGO: Practice the LEGO alone
   I'm trying → dw i'n trio

3. DEBUT PHRASES: Combine with known vocabulary (SHORT → LONG)
   I'm trying to learn → dw i'n trio dysgu
   I'm trying to speak → dw i'n trio siarad
   I'm trying to speak Welsh → dw i'n trio siarad cymraeg

4. REVIEW: Reinforce recent LEGOs
   I want to learn → dw i isio dysgu (from N-1)
   to speak Welsh → siarad cymraeg (from N-2)

5. ETERNAL: Long phrases for spaced repetition
   I'm trying to learn to speak Welsh → dw i'n trio dysgu siarad cymraeg
```

## Full Example: Welsh Course Rounds 1-6

```
ROUND 1 - S0001L01: "I want" → "dw i isio"
  INTRO: I want → dw i isio
  LEGO: I want → dw i isio
  (No DEBUT - nothing to combine yet!)

ROUND 2 - S0001L02: "to speak" → "siarad"
  INTRO: to speak → siarad
  LEGO: to speak → siarad
  DEBUT: I want to speak → dw i isio siarad

ROUND 3 - S0001L03: "Welsh" → "cymraeg"
  INTRO: Welsh → cymraeg
  LEGO: Welsh → cymraeg
  DEBUT: to speak Welsh → siarad cymraeg
  REP: I want to speak → dw i isio siarad

ROUND 4 - S0002L01: "to learn" → "dysgu"
  INTRO: to learn → dysgu
  LEGO: to learn → dysgu
  DEBUT: to learn Welsh → dysgu cymraeg
  DEBUT: I want to learn → dw i isio dysgu
  DEBUT: I want to learn Welsh → dw i isio dysgu cymraeg
  DEBUT: I want to learn to speak Welsh → dw i isio dysgu siarad cymraeg
  REP: to speak Welsh → siarad cymraeg

ROUND 5 - S0002L02: "I'm trying" → "dw i'n trio"
  INTRO: I'm trying → dw i'n trio
  LEGO: I'm trying → dw i'n trio
  DEBUT: I'm trying to learn → dw i'n trio dysgu
  DEBUT: I'm trying to speak → dw i'n trio siarad
  DEBUT: I'm trying to speak Welsh → dw i'n trio siarad cymraeg
  REP: I want to learn to speak Welsh → dw i isio dysgu siarad cymraeg
  REP: to learn Welsh → dysgu cymraeg
  REP: I want to learn → dw i isio dysgu

ROUND 6 - S0003L01: "I'm going to" → "dw i'n mynd i"
  INTRO: I'm going to → dw i'n mynd i
  LEGO: I'm going to → dw i'n mynd i
  DEBUT: I want to try → dw i isio trio
  DEBUT: I'm going to try → dw i'n mynd i drio
  DEBUT: I'm going to speak → dw i'n mynd i siarad
  DEBUT: I'm going to learn → dw i'n mynd i ddysgu
  DEBUT: I'm going to try to speak → dw i'n mynd i drio siarad
  DEBUT: I want to try to speak Welsh → dw i isio trio siarad cymraeg
  DEBUT: I want to try to learn Welsh → dw i isio trio dysgu cymraeg
  ETERNAL: I'm going to speak Welsh → dw i'n mynd i siarad cymraeg
  ETERNAL: I'm going to try to learn Welsh → dw i'n mynd i drio dysgu cymraeg
```

## Key Observations

1. **DEBUT phrases only use available vocabulary**
   - Round 1: No DEBUT (nothing available)
   - Round 2: Can only use Round 1
   - Round 6: Can use Rounds 1-5

2. **Phrases BUILD UP in complexity**
   - Start: 2 words (I'm going to try)
   - Middle: 3-4 words (I'm going to speak Welsh)
   - ETERNAL: 5+ words (I'm going to try to learn Welsh)

3. **REP reviews recent LEGOs**
   - Focus on N-1, N-2, N-3
   - Keeps recent vocabulary active

4. **ETERNAL phrases are LONG**
   - 10+ syllables
   - Used for spaced repetition over months

## M-LEGO Build-up Pattern

M-LEGOs have components that are taught BEFORE the full LEGO:

```
M-LEGO: "I want" → "我想"
Components: ["I" → "我"], ["want" → "想"]

Learner sees:
1. I → 我
2. want → 想
3. I want → 我想  ← full M-LEGO
```

Then DEBUT phrases use the M-LEGO:
```
4. I want to speak → 我想说
5. I want to speak Chinese → 我想说中文
...
```

## Particle Inference

Particles are NOT taught explicitly. Learner infers from context:

```
Components: good → 好
M-LEGO: Is it good? → 好吗

Learner sees:
1. good → 好
2. Is it good? → 好吗

They figure out 吗 = question marker from the contrast!
```

## Apply This Pattern

When building a course:
1. Think about what the LEARNER will experience
2. Ensure phrases only use what they've learned
3. Build from simple to complex
4. Include ETERNAL phrases for long-term retention
5. Let grammar emerge from context, don't explain it
