# SSi Translation Methodology

The goal of SSi translation is to **minimize cognitive load for learners** by creating predictable, consistent translations that pass ZUT (Zero Uncertainty Test) from the learner's perspective.

## The Core Problem

When an English speaker sees "I want to speak", they need to produce the target language. If we've taught them multiple ways to say "want" or "speak", they face uncertainty: *"Which one do I use here?"*

**ZUT Failure** = Learner hesitation because they can't predict the correct form
**ZUT Pass** = Learner confidently knows exactly what to produce

## The Solution: Reduced Variability

For SSi courses, **consistency trumps naturalness**, especially in early seeds (1-100).

Native speakers use varied vocabulary. Learners need predictable patterns. We sacrifice some naturalness to give learners automatic retrieval.

---

## TWO ABSOLUTE RULES

### Rule 1: NEVER Change Canonical Meaning

The canonical seed defines the exact concept to teach. Translate it faithfully.

```
Canonical: "And I want you to speak German with me tomorrow"

WRONG: "Und ich will morgen Deutsch mit dir sprechen"
       (I want to speak German with you tomorrow - changed WHO speaks)

RIGHT: "Und ich will, dass du morgen Deutsch mit mir sprichst"
       (I want that you speak German with me tomorrow - preserves meaning)
```

Even if the grammar is complex (subjunctive, etc.), preserve the canonical meaning.

### Rule 2: Prefer Cognates (Seeds 1-100)

Cognates create instant recognition and build semantic networks.

**Process:**
1. For each English word, check if a synonym has a target cognate
2. If yes, use the cognate in target AND adjust English if needed
3. Balance cognate preference with English naturalness

```
English: "as often as possible"
Check: "often" → synonym "frequently" → German cognate "frequent" ✓

Target: "so frequent wie möglich" or "so häufig wie möglich"
        (häufig is cognate with "heavy/heave" - less obvious)

Better: Keep "so oft wie möglich" - "oft" is short and learnable
```

**Cognate preference is STRONG but not absolute** - don't force awkward constructions.

---

## ZERO VARIATION Principle

### Same English → Same Target (Always)

Once you translate an English pattern, that translation is **locked** for the entire course.

```
First occurrence:
  "I want" → "ich will"

Every subsequent occurrence:
  "I want" → "ich will" (ALWAYS)

NEVER: "ich will" sometimes, "ich möchte" other times for "I want"
```

### Different English → Can Be Same or Different Target

The reverse is fine - multiple English forms can map to one target:

```
"I want to" → "ich will"
"I'd like to" → "ich möchte"  (different English = can be different target)
```

### First-Come-First-Served

The first translation choice becomes canonical. Don't change it later even if you think of a "better" option.

```
Seed 5: "speak" → "sprechen" (LOCKED)
Seed 50: Tempted to use "reden"? NO - "speak" is already locked to "sprechen"
```

**Exception:** If you discover a genuine error (wrong meaning, grammar mistake), fix it. But don't change correct translations just for stylistic preference.

---

## Register Decision

Choose ONE register for the entire course. Document it in your language analysis.

### German Example
- **Informal (du)**: For conversational, friendly courses
- **Formal (Sie)**: For business/professional contexts

**Pick one and maintain it throughout:**
```
Register: informal (du)

"you want" → "du willst" (ALWAYS)
NEVER: "Sie wollen" mixed in
```

### Other Languages
- **Spanish**: tú vs usted
- **French**: tu vs vous
- **Japanese**: casual-polite (です/ます) vs casual (だ/plain)
- **Korean**: 해요체 vs 합니다체

---

## Semantic Distinctions to Preserve

Some English distinctions SHOULD map to different target words:

### speak vs talk
```
"speak" (formal, language-focused) → "sprechen"
"talk" (casual, conversation) → "reden"
```
This is correct because English speakers already distinguish these.

### know (facts) vs know (people)
```
"I know the answer" → "Ich weiß die Antwort" (kennen/wissen distinction)
"I know him" → "Ich kenne ihn"
```

### Other common distinctions to preserve
- remember (retain) vs remember (recall)
- see (perceive) vs see (meet)
- make vs do (if target language distinguishes)

**Key insight:** If English speakers already intuit a distinction, preserve it in target. If English conflates meanings that target separates, pick ONE target form and be consistent.

---

## Translation Workflow

### During Pass 1

1. **Translate naturally first** - get the meaning right
2. **Check against prior translations** - have you used this pattern before?
3. **Lock in vocabulary** - once used, a translation is fixed
4. **Note problem areas** - verbs that split, ambiguous constructions

### Track These Patterns

| English | Target | Locked at Seed |
|---------|--------|----------------|
| I want | ich will | S0001 |
| to speak | sprechen | S0001 |
| I'm trying | ich versuche | S0002 |

### Save Analysis After Pass 1

Your translation analysis should include:
- Register choice
- Problem verbs (English words that map to multiple targets)
- Golden keys (frequent patterns)
- ZUT concerns (genuinely ambiguous seeds)

## Examples by Language

### German (deu_for_eng)
- Register: informal (du)
- Strong cognate potential with English
- Watch: modal verb word order, separable verbs

### Spanish (spa_for_eng)
- Register: informal (tú)
- Cognate-rich (Latin roots)
- Watch: ser/estar distinction, subjunctive triggers

### Mandarin (zho_for_eng)
- No register markers (pronouns same)
- Few cognates - focus on consistency
- Watch: aspect particles (了, 着, 过), measure words

### Japanese (jpn_for_eng)
- Register: casual-polite (です/ます)
- Cognates from English loanwords (カタカナ)
- Watch: give/receive verbs, potential forms

---

## Quality Checklist

Before completing Pass 1, verify:

- [ ] Register consistent throughout
- [ ] Same English pattern → same target translation
- [ ] Cognates used where natural (seeds 1-100 especially)
- [ ] Canonical meaning preserved (no simplification)
- [ ] Problem verbs documented with disambiguation rules
- [ ] No unexplained variation in core vocabulary

---

## Remember

**You're not translating for native speakers.** You're creating a learning system where English speakers can confidently produce target language because every pattern is predictable.

Learners need consistency more than they need native-level variety, and variation can come later (seeds 200+) once automaticity is established. **But consistency is not a licence for stiff text, and never on the known side.** Kai ruled on 2026-08-06: grammatical correctness is a HARD constraint and naturalness near-hard — "it shouldn't sound very weird, especially when English is the target language… sometimes we might need to pick something slightly suboptimal for ZUT reasons, but usually that's not necessary." A stilted line accepted for ZUT reasons is a rare exception you justify case by case, not the default.
