# Practice sentences that never use the word they teach

*Rebuilt check, run 28 August 2026.*

## The rule

When a lesson teaches a word, the practice sentences built for that lesson are there to
introduce it. A sentence that never uses the word it was built to teach is a defect: the
learner is promised one word and drilled on another.

Every sentence has two sides — the prompt in the language you already speak, and the
answer in the language you are learning. **The new check reads both.** The old one read
only the prompt side.

## What changed

The old check decided mechanically whether "wanted" counted as "want", by stripping word
endings from a list written out by hand for each language. Only four languages ever got a
list. Everywhere else it returned **zero** — and a zero from a check that never looked
reads exactly like a clean bill of health.

The lists are gone. Cheap readers now read each doubtful sentence and say whether it uses
the word — something they can do in any language without anyone writing down its grammar
first. Nothing in the new check is specific to any language.

## How much it can speak on

| | courses | practice sentences |
|---|---:|---:|
| old check | 15 | 30,106 |
| new check | 119 | 295,893 |

That is the whole estate, across the 24 languages learners are taught *from*. Every paid
course taught from English used to sit in the blind spot.

## The funnel

Across the whole estate, before any reading:

- **591,786** checks — every practice sentence, both sides
- **555,228** cleared instantly, because the sentence plainly contains the word
- **1,648** had nothing to check — a blank word or a blank sentence
- **34,910** left for a reader — 5.9% of everything

So 94 checks in every 100 cost nothing. Only the doubtful ones are read.

*"Read" is how many sentences a reader had to look at; the rest were cleared without
reading. "Raw" is what the first reader accused. "Confirmed" is what survived a second
reader whose job was to overturn it.*

Where a course shows a sample, the raw list was too long to confirm every line in one
sitting, so a fixed, evenly-spaced slice was confirmed instead and the proportion that
held is given. Those are the only numbers taken from a sample; nothing else on this page is.
