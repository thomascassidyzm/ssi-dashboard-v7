# Practice sentences that never use the word they teach

*Rebuilt check, second run, 28 August 2026 — the run that applies the acceptance rule.*

## The rule, and why there are two of them

When a lesson teaches a word, the practice sentences built for it exist to introduce it. A sentence
that never uses that word is a defect: the learner is promised one word and drilled on another.

Every sentence has two sides, and **they are judged by different rules**. This is the whole point of
this run, and the first run had it wrong.

**The side the learner is LEARNING is strict.** The sentence must contain the taught word in the
exact form it was taught. An inflected form does not count — teach the form, get the form. Two
things are allowed: the words of a multi-word item may be split apart by another word, and a
difference so slight the learner would barely notice it — a mild softening mutation, or a slightly
different vowel ending.

**The side the learner ALREADY SPEAKS is deliberately looser.** A different ending, tense, case or
contraction is fine, because that side has to be *grammatical* in the learner's own language. Only a
genuinely different word is a defect. The test is whether the learner would connect the two
instantly, without stopping to think.

## What the first run got wrong

The first run used one set of reading instructions for both sides — and it used the *loose* one. So
on the strict side it accepted any inflected form as a pass, which is exactly what that side
forbids. Worse, the mechanical pre-filter cleared that side on a loose match too, so an inflected
form was thrown out before any reader ever saw it.

**The retrospective check was looser than the gate it was supposed to be policing.** Every number
from the first run's strict side understates. Those rows have been re-read rather than patched.

Re-reading found **497 defects the first run missed entirely**.

## Where this rule is written down

The asymmetry is in the methodology canon and the reading instructions now quote it rather than
paraphrase it. Three things needed flagging rather than quietly deciding, and they are set out in
full in a companion note: the canon's wording on splitting reads the opposite way to the ruling
(the running code has always resolved it the ruling's way); the mild-mutation tolerance is not in
the canon anywhere and should be added; and the first run's error above.

## The funnel

Across the whole estate, before any reading:

- **591,786** checks — every practice sentence, both sides
- **554,923** cleared mechanically, because the sentence plainly contains the word
- **1,648** had nothing to check — a blank word or a blank sentence
- **35,215** left for a reader

The mechanical stage can only ever say *fine*. It can never call something a defect, and where it
cannot clear something it hands it on. On the strict side its clearing test *is* the rule, which is
why almost everything that reaches a reader there turns out to be real.

## The plainest finding, and it needed no reader at all

Counting mechanically across the whole estate: **576 lessons have no practice sentence at all that
contains the word they teach.** Not one. The lesson word is never practised anywhere in its own set.

That splits in two:

- **220** where a sentence comes within a single character of the lesson word. These are mostly a
  **misspelling in the lesson word itself** — the sentences are right and the lesson is wrong.
  Armenian alone has 126. *Caveat: in Welsh this bucket is largely soft mutation, which is a
  legitimate pass, not a defect.*
- **356** where nothing comes close. These are genuine — German has 68, none of them spelling.

Worked examples, read verbatim from the live database:

- A German lesson teaches **deine Hilfe** ("your help"). Its three practice sentences are *deine*,
  *deine Idee*, and *sie hat deine Idee gefunden*. The word *Hilfe* never appears.
- A German lesson teaches **ich hatte unrecht** ("I was wrong"). Its sentences are *ich hatte*,
  *sie hatte*, *er hatte*. The word *unrecht* never appears.
- A German lesson teaches **führt hinunter** ("goes down"). Every sentence is *er führt…*.
  *hinunter* never appears.
- An Armenian lesson teaches **արավոտ** for "morning", but all three of its sentences spell it
  **առավոտ**. The sentences are right; the lesson word has a typo.

## The looser side

The looser side was read in the first run under instructions that were already, in substance, the
loose rule. Two checks were run to see whether the canon's own wording changes the answer, and the
difference between them is worth stating because it corrects a number I published earlier today.

- **Same reading tier, both runs: 98.4% agreement.** A full slice of 316 Welsh rows was re-read
  under the canon wording by the same tier of reader as the first run. It accused 262 where the
  first run accused 267. That isolates the change in wording.
- **A cheaper reader, 240 rows: 89.6% agreement**, accusing 141 against 155. I first reported this
  as the agreement rate for the wording change. It is not: that sample was read by a cheaper tier
  than the run it was compared against, so it measures the change of reader as much as the change
  of instructions. The 98.4% figure is the one that answers the question asked.

Either way the direction is the same and it is the one the canon intends: the canon's wording
accuses slightly *fewer* on this side, not more. Disagreements go both ways and both look right —
*whom* against *who* now passes as a case variation, while *of those places* against *from those
places* is now correctly called a different preposition.

The first-run numbers for this side therefore stand, with that agreement rate attached rather than
a claim of a full re-read.

## What is not settled

- The strict side's confirmed counts come from **samples**, not the full raw lists; the sample sizes
  are on each line.
- Only the four courses above were read in full. The other 115 have a candidate list, not verdicts.
- Whether the mild-mutation tolerance should be written into the canon is a decision for Kai, and so
  is what to do about lessons whose own word is misspelled.
