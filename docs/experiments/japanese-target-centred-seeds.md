# Japanese Target-Centred Seeds: Layer 0 (Meta)

*30 seeds designed from Japanese-first principles - January 2026*

---

## Design Principles

1. **Target-first**: Japanese sentences chosen for naturalness, then back-translated
2. **Tiling constraint**: Each seed tiles from its component LEGOs
3. **Progressive introduction**: Each seed introduces 1-2 new LEGOs
4. **Layer 0 focus**: Meta conversation about learning itself
5. **Colloquial register**: Casual forms, lowest cognitive load
