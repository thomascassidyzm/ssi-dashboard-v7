# Seed Layer Analysis - Mapping 668 Seeds to Speakability Layers

*Analysis document - January 2026*

---

## The Speakability Layers (Tom's Framework)

| Layer | Name | Purpose |
|-------|------|---------|
| **0** | Meta | Talk about the learning journey itself |
| **1** | Basic Needs | Coffee, water, tired, rest, need X |
| **2** | Contributing | Join in, react, add to the moment |
| **3** | Self & Perspectives | Opinions, preferences, meaningful self-expression |
| **4** | Involving Others | He said, she thinks, I met someone who... |
| **5** | Sophisticated | Abstract ideas, nuanced views, uncommon perspectives |

**Across all layers**: Questions, Responses, Statements

## Key Insight: The 668 Seeds ARE the Concepts

The seeds represent universal communicative functions. What varies by language direction is:

1. **Order**: Which seeds to front-load based on L1→L2 transfer
2. **Expression**: How to express each seed naturally in the target
3. **Grouping**: Which seeds can be batched together (share grammar patterns)

For **distant languages** (English→Japanese):
- Front-load Layer 0 (meta) - immediately useful, forgiving context
- Front-load simple patterns from Layer 2 (contributing)
- Delay Layer 5 (sophisticated) - requires grammar that may not exist early

For **close languages** (Spanish→Portuguese):
- Can move through layers faster
- Leverage cognates to accelerate vocabulary
- Grammar patterns mostly transfer

## Proposed: The First 30 Seeds by Layer (Language-Agnostic)

For maximum speakability in first 30 days:

### Seeds 1-10: Meta Foundation
- I want to speak X with you
- I'm learning / trying to learn
- How long have you been learning?
- I don't worry about mistakes
- Could you say that again slowly?

### Seeds 11-20: Basic Needs + Contributing
- I'm tired / I feel okay
- I need X / I want X
- That's a good idea
- Thank you / No problem
- What do you think?

### Seeds 21-30: Light Self + Involving Others
- I like / I don't like
- I think that...
- He/she wants to...
- My friend said...
- Do you mind if...?

This gives the learner:
- Ability to talk ABOUT learning (repair, progress, struggle)
- Ability to express basic needs
- Ability to participate in simple conversation
- Ability to reference other people
- Question + Response + Statement patterns in each batch
