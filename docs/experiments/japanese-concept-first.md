# Japanese Concept-First Course Design

## Principles

1. **Target-first**: Start with natural Japanese, back-translate to English
2. **No tiling constraint**: LEGOs are natural building blocks, not forced reconstructions
3. **Vocab progression**: Order by what builds naturally in Japanese
4. **Simplest formality**: Use polite-casual (です/ます) - universally safe, not overly formal
5. **Maximum speakable units**: Each LEGO combines with previous ones immediately

## Formality Choice: Polite Form (です/ます)

Why not casual (dictionary form):
- Sounds rude to strangers
- Learners would need to relearn everything for real conversations

Why not honorific (keigo):
- Too complex for beginners
- Rarely needed except business contexts

です/ます is the sweet spot - polite enough for any situation, simple enough to learn.

## Phase 1: Core Identity & Copula (Seeds 1-10)

### Concept 1: Self-identification
```
Japanese: 私です
Back-translation: It's me / I am
LEGOs:
  L1 [A]: "I/me" → "私"
  L2 [A]: "am/is" → "です"
```

### Concept 2: Basic question
```
Japanese: 何ですか
Back-translation: What is it?
LEGOs:
  L1 [A]: "what" → "何"
  L2 [M]: "is it?" → "ですか" (です + か question marker)
```

### Concept 3: This/that identification
```
Japanese: これは何ですか
Back-translation: What is this?
LEGOs:
  L1 [A]: "this" → "これ"
  L2 [A]: "as for (topic)" → "は"
```

## Key Differences from English-First Approach

| Aspect | English-First | Concept-First |
|--------|--------------|---------------|
| Starting point | English sentence | Abstract concept |
| Target language | Translation (may be unnatural) | Native expression |
| Seed order | Fixed canonical order | Flexible by language |
| Tiling | Required (every char covered) | Not needed |
| Back-translation | N/A | Derives from target |
| Verb forms | Mixed (following English tense) | Consistent (ます form) |
| Formality | Whatever fits English | Chosen for pedagogy |

## Implementation Notes

1. **No tiling validation** for concept-first courses
2. **New course type flag**: `concept_first: true` in course metadata
3. **Seed structure changes**:
   - `concept_text`: Abstract concept description
   - `target_text`: Natural target language (PRIMARY)
   - `known_text`: Back-translation (DERIVED)
4. **Agent instructions**: "Create natural Japanese, then back-translate"

## Vocabulary Summary (Seeds 1-50)

### Core LEGOs Introduced

**Phase 1 (Identity & Copula)**: ~10 LEGOs
- Pronouns: 私, あなた, 彼
- Demonstratives: これ
- Particles: は, の
- Copula: です, ですか
- Responses: はい, いいえ, 違います
- Noun: 本

**Phase 2 (Basic Verbs)**: ~18 LEGOs
- Verbs: 話します, 分かります, 食べます, 飲みます, 行きます, 来ます, 見ます, 聞きます, 読みます, 書きます, 勉強します
- Particles: を, に
- Nouns: 日本語, 日本
- Adverb: 少し
- Negative: 分かりません

**Phase 3 (Desire & Intent)**: ~10 LEGOs
- たい form verbs: 食べたいです, 話したいです, 行きたいです, 勉強したいです
- て-form compounds: 話してみます
- Potential: 話せます, 読めません
- Obligation: 行かなければなりません, 行かなくてもいいです
- Request: 教えます, てください

**Phase 4 (Time & Location)**: ~20 LEGOs
- Time: 今, 今日, 明日, 昨日, いつも, 時々, 毎日, 朝, 夜, 週末, 来週
- Location: ここ, そこ
- Particle: で
- Nouns: 朝ご飯, 音楽, 友達
- Verbs: 運動します, 散歩します, 会います
- Past forms: 見ました, 食べました, 行きませんでした

**Total after 50 seeds**: ~58 unique LEGOs

### Recombination Potential

By seed 50, learners can construct sentences like:
- 明日、友達と日本に行きたいです (Tomorrow I want to go to Japan with a friend)
- 昨日、日本語を勉強しませんでした (I didn't study Japanese yesterday)
- 毎日、朝ご飯を食べます (I eat breakfast every day)
- 週末に来てください (Please come on the weekend)

This demonstrates the SSi principle: maximum speakable units from minimal vocabulary.
