### The -たい Master Key

The -たい suffix is the single highest-ROI pattern in Japanese:

| Form | Meaning | Example |
|------|---------|---------|
| -たい | want to | 話したい |
| -たくない | don't want to | 話したくない |
| -たかった | wanted to | 話したかった |
| -たくなかった | didn't want to | 話したくなかった |

**4 forms → 31 collocations covered**

## Teaching Recommendations

### Priority 1: Establish Foundation Patterns

1. **Teach -たい FIRST** - Covers 26 "want" collocations
2. **Use 話す as anchor verb** - Demonstrate ALL patterns with it
3. **Teach potential form early** - 12 collocations covered
4. **Teach volitional + とする** - 11 collocations covered

### Priority 2: Handle Problem Verbs Strategically

**Cannot delay these entirely - they appear in first 150 seeds. Strategy: minimal variation, not zero.**

| Verb | Recommended Approach |
|------|---------------------|
| think | Start with 思う ONLY. Add 考える later. |
| learn | Pick ONE primary: 勉強する for "study", add others contextually |
| know | Start with 分かる for "understand", add 知っている later |
| give | Use あげる only initially. Delay くれる/もらう to intermediate |
| see | 見る for visual, 会う for people - teach as separate concepts |

### Priority 3: Leverage Character Consistency

Point out explicitly: 話す/話したい/話せる all share 話

This builds pattern recognition and reduces perceived complexity.
