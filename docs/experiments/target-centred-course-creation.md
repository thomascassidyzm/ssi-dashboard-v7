# Target-Centred Course Creation

*A paradigm shift for structurally distant languages - January 2026*

---

## Executive Summary

For languages structurally distant from the learner's L1 (e.g., Japanese for English speakers), the traditional "English-first" approach creates unnecessary cognitive load and learner confusion.

**Target-centred course creation** inverts the process: start with the target language, choose maximally useful forms, and back-translate to show what English needs each form covers.

The result: fewer target language variants, more recombination, faster path to speakability, and maximum learner delight.

---

## Part 1: The Problem with English-First

### The Traditional Approach

English-first course creation:
1. Start with canonical English seed ("I want to speak Japanese")
2. Translate to target language
3. Extract LEGOs from translation
4. Generate practice phrases

This works beautifully for languages close to English (Spanish, French, German) where:
- Word order is similar
- One English concept ≈ one target concept
- Verb forms map roughly 1:1

### The Problem for Distant Languages

For Japanese (and similar languages), English-first creates **production uncertainty**:

| English Concept | Japanese Form | Notes |
|-----------------|---------------|-------|
| I speak | 話します | polite present |
| I want to speak | 話したいです | desire + polite |
| I'm trying to speak | 話そうとしている | volitional + progressive |
| Do you speak? | 話しますか | polite question |
| Can you speak? | 話せますか | potential + question |

**Five different Japanese verb forms** for what feels like "the same word" to an English speaker.

The learner is bombarded with variants before mastering any one. Result: **paralysis**. "Which one do I use?!"

### The Cognitive Load Problem

Each new form requires:
- New sound pattern to memorise
- New character recognition (for written)
- New "when do I use this?" decision
- New production pathway in the brain

Introducing 5 variants of "speak" early means 5x the cognitive load for expressing one concept.

## Part 2: The Target-Centred Solution

### Invert the Process

Target-centred course creation:
1. **Start with target language**: "What's a maximally useful Japanese utterance?"
2. **Choose the form wisely**: Simple, high-recombination, covers many situations
3. **Back-translate to English**: "What English needs does this Japanese form serve?"
4. **Build LEGOs from the target**: The target is primary, English is derived

### The Master Key Principle

A "master key" LEGO is one target form that unlocks many English meanings.

**Chinese Example** (we already do this well):

| Chinese | English meanings it covers |
|---------|---------------------------|
| 说 (shuō) | speak, say, talk |
| 想 (xiǎng) | want, think, miss |
| 会 (huì) | can (ability), will (future) |

One Chinese LEGO → many English concepts. The learner masters ONE form and can express MANY things.

**Japanese Target** (what we want):

| Japanese | English meanings it covers |
|----------|---------------------------|
| 話します (hanashimasu) | I speak, I talk, I will speak |
| です (desu) | am, is, are, it's |
| ほしい (hoshii) | want (thing), would like |
| できる (dekiru) | can, able to, possible |

### One Japanese LEGO → Many English Seeds

Instead of asking "how do I say 'I speak' vs 'I want to speak' vs 'I can speak'?", the learner experiences:

- Round N: Learns 話します
- Uses it for "I speak Japanese", "I talk to friends", "I will speak tomorrow"
- Later: Learns できる pattern
- Combines: 話すことができる (can speak)

Each LEGO extends capability. No confusion about variants.

## Part 3: Design Principles

### 1. Target-First Seed Design

The `target_text` is PRIMARY. The `known_text` is DERIVED (back-translation).

```
WRONG (English-first):
  known_text: "I want to speak"  → translate → target_text: ???

RIGHT (Target-first):
  target_text: "話したいです"  → back-translate → known_text: "I want to speak"
```

Both fields populated upfront, with Japanese as the source of truth.

### 2. Colloquial Register

Choose the **simplest, least formal** forms:
- Plain/casual forms over keigo
- です/ます for basic politeness (universally safe)
- Avoid complex honorifics

**Why:**
- Lowest cognitive load
- Native speakers are forgiving of learners
- Formal register can be a separate "upgrade" course later
- Matches how Japanese children actually learn

**Positioning:** "Japanese: Colloquial Course" - it's a feature, not a limitation.

### 3. Loanword Delight

Japanese has borrowed thousands of English words. These are **free vocabulary**:

| English | Japanese | Pronunciation |
|---------|----------|---------------|
| coffee | コーヒー | kōhī |
| hotel | ホテル | hoteru |
| internet | インターネット | intānetto |
| computer | コンピューター | konpyūtā |
| taxi | タクシー | takushī |
| beer | ビール | bīru |
| restaurant | レストラン | resutoran |

**Learner delight:** "Wait, that's just the English word!"

**Strategy:** Front-load loanwords wherever natural. Combine with pattern LEGOs for instant capability:
- コーヒーほしい (I want coffee) - learner knows half already!
- ホテルどこですか (Where is the hotel?)

### 4. Maximise Recombination

**LEGOs are atoms. Seeds are molecules.**

The learner never sees "seeds" - they experience LEGOs being introduced and combined. Seeds are just containers that prove LEGOs can form meaningful sentences.

**The goal:** Choose LEGOs that MULTIPLY phrases possible, not just ADD.

## Part 4: The Recombination Formula

### Combinatorial Growth

If LEGOs are chosen to recombine freely:

| LEGO # | New Phrases Possible | Cumulative |
|--------|---------------------|------------|
| 1 | 0 | 0 |
| 2 | 1 | 1 |
| 3 | 3 | 4 |
| 4 | ~6 | ~10 |
| 5 | ~10 | ~20 |
| N | ~N²/2 | Exponential growth |

**Key insight:** Each new LEGO should multiply capability, not just add to it.

### Pattern LEGOs vs Noun LEGOs

**Pattern LEGOs** (high value - these are the multipliers):
- "want ___" → ほしい
- "want to ___" → ___たい
- "can ___" → ___できる
- "is/am/are" → です

**Noun LEGOs** (medium value - slot into patterns):
- coffee → コーヒー
- Japanese → 日本語
- tomorrow → 明日

**The math:**
- 1 pattern LEGO + 10 noun LEGOs = 10 phrases
- 2 pattern LEGOs + 10 noun LEGOs = 20 phrases
- 5 pattern LEGOs + 10 noun LEGOs = 50 phrases

**Pattern LEGOs are multipliers.** Prioritise them.

### The 500 LEGO Target

Research and experience suggest:
- ~500 well-chosen LEGOs = interactive conversational confidence
- Quality of selection matters more than quantity
- 500 badly-chosen LEGOs (synonyms, variants) = confusion
- 500 well-chosen LEGOs (master keys, high recombination) = fluency

## Part 5: Language Direction Matters

### Same Target, Different Optimal Path

**Japanese for English speakers:**
- Grammar is completely foreign (SOV, particles, verb endings)
- Leverage loanwords (free nouns)
- Choose verb patterns that cover many English concepts
- Avoid introducing Japanese synonyms/variants early
- High cognitive load per grammatical LEGO

**Japanese for Korean speakers:**
- Grammar is almost free (SOV, particles, honorifics all transfer!)
- Focus on vocabulary differences
- Can introduce nuances earlier
- Low cognitive load per grammatical LEGO

**The "master key" LEGOs are different depending on learner L1.**

### The LLM Advantage

An LLM can identify optimal LEGOs for ANY language direction because it:
- Understands both source and target language
- Can assess what transfers vs. what's new
- Can evaluate recombination potential
- Can identify loanwords and cognates
- Can reason about cognitive load

This enables building optimal courses for any language pair, not just common ones.

## Part 6: Implementation for Japanese

### Optimal First ~20 LEGOs (Japanese for English speakers)

**Core Pattern LEGOs (multipliers):**
1. です (desu) - is/am/are/it's
2. ですか (desu ka) - is it? (question pattern)
3. ほしい (hoshii) - want (thing)
4. たい (tai) - want to (verb)
5. できる (dekiru) - can/able
6. ある (aru) - exists (things)
7. いる (iru) - exists (people/animals)
8. する (suru) - do/make (covers verb-nouns)

**Essential Particles:**
9. は (wa) - topic marker
10. を (wo) - object marker
11. に (ni) - direction/time
12. で (de) - location of action

**High-Value Loanword Nouns (free vocabulary):**
13. コーヒー (coffee)
14. ビール (beer)
15. レストラン (restaurant)
16. ホテル (hotel)
17. インターネット (internet)
18. メニュー (menu)

**Early Native Nouns:**
19. 日本語 (nihongo) - Japanese language
20. 明日 (ashita) - tomorrow

### Sample Phrases from Just These LEGOs

With only ~20 LEGOs, learners can produce:
- コーヒーほしい (I want coffee)
- ビールほしいですか (Do you want beer?)
- レストランどこですか (Where's the restaurant?)
- 日本語できる (I can do Japanese / I can speak Japanese)
- 明日ホテルにいる (I'll be at the hotel tomorrow)
- インターネットある? (Is there internet?)

**This is the target-centred advantage:** Maximum speakability from minimal LEGOs.

## Part 8: Testing the Hypothesis

### The Experiment

**Hypothesis:** Target-centred seed design produces better course quality than English-first design, measured by:
1. Fewer unique target forms introduced early
2. Higher recombination ratio (phrases per LEGO)
3. More loanword utilisation
4. Learner confidence (subjective, needs user testing)

### Test Approach

1. **Build 30 target-centred Japanese seeds** following these principles
2. **Run Course Builder** to decompose and generate phrases
3. **Compare metrics** against what English-first would produce:
   - Count unique verb forms introduced
   - Count unique LEGOs
   - Calculate phrases per LEGO
   - Assess loanword coverage
4. **Qualitative review** - Do the phrases feel learnable? Delightful?

### Success Criteria

- Fewer than N verb form variants in first 30 seeds
- At least X% loanword utilisation where applicable
- Recombination ratio > Y phrases per LEGO
- Qualitative: "This feels learnable" from native speaker review

## Part 11: Learnings from Layer 0 Build (January 2026)

After building 30 target-centred seeds for Japanese Layer 0 (meta conversation about learning), the following practical insights emerged:

### 11.1 Seeds vs LEGOs: Critical Distinction

**Key Learning:** Course Builder decomposes seeds INTO LEGOs, not vice versa.

The initial approach incorrectly focused on designing LEGOs first. The correct workflow:
1. Design complete **seed sentences** in the target language
2. Back-translate each seed to the known language
3. Verify **tiling constraint**: each seed must be reconstructable from its component LEGOs
4. Let Course Builder extract LEGOs and generate practice phrases

**Tiling Example:**
```
Seed: 一緒に日本語話したい (I want to speak Japanese together)
Tiles: 一緒に + 日本語 + 話したい ✓
```

If a seed cannot be reconstructed from its LEGOs, the tiling constraint fails.

### 11.2 Grammar-Baked LEGOs Work Well

Embedding particles/conjugations into LEGOs rather than teaching them separately proved effective:

| LEGO | Embedded Grammar | Why It Works |
|------|------------------|--------------|
| 一緒に | に particle | "together" is always 一緒に, never 一緒 alone |
| 日本語で | で particle | "in Japanese" always needs で |
| 間違えても | ても conditional | "even if wrong" is a single concept |

**Result:** Learner produces grammatically correct output without explicit grammar instruction.

### 11.3 Verb Form Consolidation Achieved

Target-centred design achieved the goal of minimal verb form variants:

**Verb patterns introduced in 30 seeds:**
1. ～たい (want to ~) - e.g., 話したい, 練習したい, 頑張りたい
2. ～ない (negative) - e.g., 分からない
3. Dictionary form - e.g., できる, 分かる
4. ～て form (request) - e.g., 教えて

**Only 4 verb patterns** vs. 12-14 that English-first would require for equivalent expressiveness.

### 11.4 Layer 0 (Meta) Is Loanword-Free

**Observation:** Layer 0 (conversation about learning) naturally contains no loanwords.

Loanwords like コーヒー, ホテル, etc. belong to Layer 1+ (basic needs, travel, transactions). The meta-layer uses native Japanese vocabulary for concepts like:
- 練習 (practice)
- 難しい (difficult)
- 楽しい (fun)
- 頑張る (do one's best)

**Implication:** Loanword delight kicks in at Layer 1, not Layer 0.

### 11.5 31 LEGOs from 30 Seeds

The build produced exactly 31 unique LEGOs from 30 seeds:
- 29 seeds introduced 1 new LEGO each
- Seed 27 introduced 2 LEGOs (少しずつ + 分かる)

This 1:1 ratio demonstrates efficient seed design - each seed serves a clear purpose in the curriculum.

### 11.6 Quality Assessment Results

Three analysis agents evaluated the 30 seeds:

| Metric | Score | Notes |
|--------|-------|-------|
| Overall Quality | 7.4/10 | Strong foundation, room for expansion |
| Tiling Compliance | 100% | All seeds reconstruct from LEGOs |
| Progression Logic | Strong | Steady capability growth |
| Master Key Coverage | 50% | 15 of 30 LEGOs are master keys |

**Key Finding:** Target-centred approach uses ~75% fewer verb forms than English-first would for equivalent expressiveness.

### 11.7 Colloquial Register Decision Validated

Using casual forms (です/ます politeness, but no keigo) proved correct:
- Lower cognitive load for beginners
- Native speakers understand and forgive learner-casual speech
- Forms a foundation for later "formal upgrade" course
- Matches natural language acquisition patterns

### 11.8 Recommendations for Future Builds

1. **Start with Layer 0** - Meta conversation grounds the learner
2. **Verify tiling during design** - Don't assume it works, check each seed
3. **Use the seeds document format** - Target, Known, New LEGOs, Reused, Tiles
4. **One new LEGO per seed** - Occasionally two is fine, but aim for progressive reveal
5. **Layer 1+ will introduce loanwords** - Plan for that delight factor
6. **Trust colloquial register** - Formal can come later

## Appendix B: Glossary

**Target-centred:** Course design that starts from the target language and back-translates to the known language.

**Master key LEGO:** One target language form that covers multiple known language concepts.

**Pattern LEGO:** A LEGO that functions as a grammatical pattern (verb form, particle, etc.) enabling many combinations.

**Noun LEGO:** A LEGO that is a content word (thing, place, etc.) that slots into patterns.

**Recombination ratio:** The number of producible phrases divided by the number of LEGOs introduced.

**Loanword delight:** The learner's joy when recognising that a target word is borrowed from their L1.

**Production uncertainty:** Learner confusion about which target form to produce when multiple variants exist.
