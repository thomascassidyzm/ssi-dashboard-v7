## The join

`manifest.json` maps every `line_id` to the exact database rows that line supplies audio for:

```
line_id  →  { role, text, rows: [ { table, id, seed_number, lego_index, position } ] }
```

One line can serve many rows — the same Yoruba sentence appears as a LEGO and inside several practice phrases, and is recorded once. Dedupe is **byte-exact on the target text**, so two forms differing only in a tone mark or a dot-below are treated as different lines, never merged.

`line_id` is stable only as long as this manifest is kept. Regenerating after the course grows will renumber. **Keep the manifest that went out with the recordings.**
