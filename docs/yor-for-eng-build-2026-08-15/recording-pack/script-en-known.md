# Yoruba course recording script — English prompt voice

**Course:** Yoruba for English speakers · **Your part:** English prompt voice (English)

**252 lines**, split into **5 sessions**. About 29 minutes of actual speaking in total — allow two to three times that with pauses and retakes.

> These are the English prompts a learner hears before the Yoruba. Read them plainly and unhurriedly.

## Before you start

1. Somewhere quiet. No music, no fan, no traffic if you can help it.
2. Phone or laptop is fine. Hold the phone about a hand's width from your mouth, slightly to the side.
3. **Record one session into one single audio file.** Do not try to make a separate file per line.
4. At the very start of the file, say out loud: *"English prompt voice, session one"* (then two, three...). This is how we tell your files apart.
5. **Say the line number before each line**, e.g. *"one"* ... then the line. Then pause for a breath before the next one.
6. If you fluff a line, just pause, say *"again"*, and repeat it. We will keep the last good one.

## When you are done

Send us the audio files — one per session — with the session number in the filename if you can (e.g. `yoruba-voice-EN-session-1.m4a`). Anything readable is fine; we can rename them.

Please also tell us anything that felt wrong, unnatural, or like something no one would actually say. That feedback is as valuable to us as the recording.
