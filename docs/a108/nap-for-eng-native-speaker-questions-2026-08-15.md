# nap_for_eng — questions for a Neapolitan speaker

**Date:** 2026-08-15 · **Course:** nap_for_eng (Neapolitan for English speakers) · **Status of build:** seeds 1–30 decomposed, text only, no audio.

Nobody on this build speaks Neapolitan. Every judgement below was made from evidence inside the
668 existing seed translations plus Neapolitan Wikipedia, and each one is a place where that
evidence ran out. **These are not technical questions.** Anyone who speaks Neapolitan can answer
them; no knowledge of the course software is needed.

Where a question is marked **BLOCKING**, the current course content contains a guess that will be
taught to learners until it is ruled on.

---

## A. Where the clitic goes (me / te / ce)

This is the single biggest source of uncertainty in the build, because it decides how phrases
can be cut into pieces.

The existing translations do it two different ways:

- seed 6: `stongo pruvanno a **m'**arricurdà na parola` — the *me* sits on the verb "remember"
- seed 10: `**me** pozzo arricurdà tutta 'a frase` — the *me* has jumped to the front, onto "can"
- seed 24: `nun **m'**aggi'a puté arricurdà facilmente` — jumped to the front again

**A1. BLOCKING — "I want to remember a word."** Which is right?
   - (a) `voglio m'arricurdà na parola`
   - (b) `me voglio arricurdà na parola`
   - (c) both are fine
   *Why it matters:* we currently avoid this sentence entirely, which makes the "remember" lesson
   thinner than it should be.

**A2. "I'd like to be able to remember the whole sentence."**
   - (a) `vurria puté m'arricurdà tutta 'a frase`
   - (b) `me vurria puté arricurdà tutta 'a frase`
   - (c) something else — please write it

**A3.** Is there a simple rule you could state? For example: *"after a / 'e / pe + verb the little
word stays on the verb; with voglio / pozzo / aggi'a it jumps to the front."* If that is the rule,
say so — it will let us build a lot more sentences safely.

## B. "as … as I can" — the frame `'o cchiù … ca pozzo`

The translations use one frame for several English ideas:

- seed 3: `'o cchiù spisso ca pozzo` — as often as possible
- seed 7: `'o cchiù ca pozzo` — as hard as I can
- seed 28: `'o cchiù ampressa ca **puoje**` — as soon as **you** can
- seed 29: `'o cchiù ampressa ca **pozzo**` — as soon as **I** can

**B1.** Is `ca pozzo` / `ca puoje` genuinely how a Neapolitan speaker says this, or is it a
translation from Italian? If there is a more natural everyday way, please write it.

**B2. BLOCKING.** Seed 13 is `parle napulitano buono assaje` ("you speak Neapolitan very well").
We have deliberately **never** attached `'o cchiù spisso ca pozzo` to a *you* sentence, because
`pozzo` means *I* can — "you speak as often as **I** can" would be nonsense. Is that right, or is
`ca pozzo` frozen as a fixed phrase that works with any subject?

---

## C. `pruvà` — try, or practise, or both?

Seed 5 uses `aggi'a pruvà a parlà` for "I'm going to **practise** speaking".
Seed 7 uses `voglio pruvà` for "I want to **try**".

**C1.** Does `pruvà` really cover both *try* and *practise*, or is there a separate word for
practising a language (the way Italian has *fare pratica*)? If there is, we should use it — the
course currently teaches one word for both.

---

## D. `me piace` — with or without `'e`?

- seed 26: `**me piace 'e** me sentì …` — I like feeling …
- seed 51: `**me piace** fà cose 'nteressante …` — I like doing interesting things
- seed 239: `a màmmema **le piace 'e** leggere` — my mum likes reading

**D1. BLOCKING.** When does `'e` appear after `me piace` and when does it not? We have taught
`me piace 'e` as the fixed form for "I like". If seed 51's `me piace fà` is equally correct, the
learner will meet a contradiction at seed 51.

---

## E. `comme si fosse` — "as if"

Seed 26: `me piace 'e me sentì **comme si fosse** quase pronto pe jì`
("I like feeling as if I'm nearly ready to go").

**E1.** We have taught `comme si fosse` as a single fixed lump meaning "as if". Is it fixed, or
does the ending change with the person (as if **you** were, as if **he** were)? If it changes,
please write the *you* and *he* versions.

## F. Spelling of "in" / "on"

The 668 translations spell this three different ways:

| Spelling | Seeds | Example |
|---|---|---|
| `'n` as a separate word | 4 seeds (4, 160, 379, 462) | `comme dicere quaccosa **'n** napulitano` |
| `'ncopp'a` (joined, with apostrophe) | 12 seeds (83, 84, 133, 134, 195, 358 …) | `ditto **'ncopp'a** ll'amico tujo` |
| `ncopp'a` (joined, no apostrophe) | 1 seed (310) | `scrivere na storia **ncopp'a** chill'ommo` |

Neapolitan Wikipedia's own article on Naples writes it joined and **without** a leading apostrophe:
`'A cità 'e Napule sta **ngopp'a** cinche culline` — and with a **g**, not a c.

**F1.** Which should the course use throughout — `'ncopp'a`, `ncopp'a`, or `ngopp'a`?

**F2.** Seed 195 has `'ncopp''a tavula` with **two** apostrophes in a row, where seed 83 has
`'ncopp'a`. Is the double apostrophe in seed 195 simply a typo?

## G. One small thing that may be a typo

**G1.** Seed 240: `a pàtemo nun **le** piace 'e fernì 'e parlà` — "my dad doesn't like to stop
talking". Is `le` right here, or should it be something else? (Seeds 239 and 242 use `le` the same
way. We believe it is the ordinary "to him/her" word and **not** a mis-spelled article, but we
could not confirm it.)

## I. Two glosses we chose that a speaker may want to overrule

**I1.** `canoscere` — we teach it as **"to get to know"** rather than "to meet", because the course
already uses `ce vulimmo vedé` for "we want to meet" (seed 18) and the method forbids one English
phrase having two Neapolitan translations. Is "to get to know" a fair everyday gloss for
`canoscere`?

**I2.** `sujo` — seed 20 uses `'o nomme sujo` for "**his** name" and seed 21 uses the identical
`'o nomme sujo` for "**her** name. We have taught both deliberately, so the learner discovers that
Neapolitan does not distinguish them. Is that correct — does `sujo` really cover both?
