# Welsh North — 401 canon sentences for a native read

_Published 2026-08-21._

This is 401 Welsh sentences from a rebuild of the Welsh North course. A machine produced this Welsh in one batch on 2026-07-16, and no human has read any of it yet. It is meant to be **northern** Welsh (isio, efo, mae o, rŵan — not moyn, gyda, mae e, nawr). Please read through and mark anything that's wrong, unnatural, or sounds southern instead of northern. Each row shows the English sentence this was translated from, and the Welsh translation to check. The Welsh came from ten different course builds that were each supposed to produce the same sentence — almost all of them agree with each other, but a handful don't, and those are listed first below so you can pick the right one.
