# Health sector conversations v3
## Complete linear flows: nurse-patient and doctor-patient

**What changed from v2:** every interaction is now written as complete conversations that run start to finish - healthcare worker, patient, healthcare worker, patient, and so on - rather than layered by turn. Each flow is a coherent path a real conversation could take. Between them, the flows for each interaction cover the main response families and follow-up moves, so nothing important is lost. More variants can be added later without touching the structure.

**Reading the labels:** each flow has a short tag saying which path it threads (e.g. *happy path*, *question*, *problem*, *safety-critical ⚠*, *human moment*). **HW** = healthcare worker, **P** = patient. **⚠** still marks the safety-critical lines a learner must catch first time.

Both linguistic-situation openers (Welsh and English) now appear for the nurse sequence *and* the doctor sequence.

# Design notes for course production

**Each flow is a self-contained listening/speaking unit.** Because they now run straight through, any single flow can drop into an exercise as-is: play it for listening, gap the patient turns for comprehension, gap the HW turns for production practice, or role-play it live. No reassembly from layers.

**Coverage is spread across the flows, not within them.** For each interaction the three flows between them hit the main response families and the key follow-up moves. A learner who works all three has met the happy path, the question, and the problem/safety-critical version of every context.

**The ⚠ flows are the priority strand.** Every safety-critical line now sits inside a complete conversation showing the correct handling from opening to close - stop and re-check identity, hold and examine, write it down, never smooth over. These are the flows for heaviest repetition and 2x listening.

**Linguistic openers now lead both sequences.** Nurse and doctor each get the Welsh and English variants as full flows, so the language-situation contract can be taught as its own short module before either clinical sequence begins.

**Clinical caveat unchanged:** the conversational shapes are solid, but the clinical specifics (nil-by-mouth medication handling, safety-netting thresholds, the blood-sugar figures) want a pass from a practising clinician before anything ships.

**Still on the list for later:** phone conversations, talking to relatives, three-way paediatric interactions, consent. Breaking bad news stays out of scope for a beginner course.
