# eus_for_eng — `gustuko` → `gustatzen zait` conversion list

**For Deborah to review.** R78 flagged that "gustuko dut" should be the standard "gustatzen zait". This affects **60 phrases** across the whole course. The conversion isn't just a word-swap: the liked thing becomes the subject (absolutive), the experiencer becomes dative (zait/zaizu/zaio…), plural liked things take `zaizkit/zaie`, and a liked *action* nominalises (e.g. `hitz egiten` → `hitz egitea`).

**Status: ALL 60 APPLIED** (text). Audio regeneration runs in the final pass. This doc is a record of the changes — not a list of questions. Only **two** items are worth a native sanity-check (see bottom).

- ⚠️ = this phrase had an **extra error** beyond `gustuko` (wrong number, wrong case, or an English/Basque mismatch) that I also fixed.

Note: where the English uses a plural ("dogs", "ideas", "things", "conversations") the current Basque was singular — I've made the Basque plural to match. If you'd rather change the English instead, just say.

1. **R328** — "I'm glad to see you" was `ikusi gustuko dut`, a broken construction. The LEGO is "to see" (`ikusi`), so I changed it to **"I like seeing you" / `zu ikustea gustatzen zait`**. OK to change the English meaning slightly like that?
2. **R685/686 "most people…"** — I treated "jende gehiena" (most people) as grammatically **singular** → `gehienari … gustatzen zaio`. Confirm that's right and not a plural form.
