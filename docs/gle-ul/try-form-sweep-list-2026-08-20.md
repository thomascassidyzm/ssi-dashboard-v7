## The frame no progressive can fill

English says "try/tried" but the Irish does NOT use `ag iarracht`, because there is no complement to govern:

| seed | English | Irish |
|---|---|---|
| 7 | I want to try as hard as I can today | `Tá mé ag iarraidh iarracht a dhéanamh chomh crua agus a thig liom inniu` |
| 8 | I'm going to try to explain what I mean | `Tá mé ag gabháil iarracht a dhéanamh ar a mhíniú goidé atá i gceist agam` |
| 146 | nothing seems to be working since we tried to fix it | `Níl a dhath ag obair de réir cosúlachta ó rinne muid iarracht é a chur ceart` |
| 236 | I know someone who said that she was going to try to help | `Tá aithne agam ar dhuine a dúirt go raibh sí ag dul a dhéanamh iarrachta ar chuidiú` |
| 407 | shouldn't we try to set a good example? | `nár chóir dúinn iarracht a dhéanamh dea-shampla a thabhairt?` |
| 491 | I love the way you try to help | `Is aoibhinn liom an dóigh a ndéanann tú iarracht cuidiú` |
| 541 | it's a good idea to try and breathe slowly | `is smaoineamh maith é iarracht a dhéanamh análú go réidh` |
| 579 | we've often tried | `is minic a rinne muid iarracht` |

Whatever #552 picks must answer this frame too, or the course teaches two forms.
