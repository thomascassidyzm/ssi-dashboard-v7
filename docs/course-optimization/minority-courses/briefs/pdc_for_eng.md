## Orthography

**Standard: Buffington–Barba–Beam (BBB), Lancaster norm.** This is the scholarly/literary orthography (Buffington & Barba grammar; Beam's dictionaries; used by Louden and padutchdictionary.com). **Rejected:** the Amish English-phonetic spelling system (the one used in most sectarian publishing, e.g. "Es Nei Teshtament" spellings). Never mix the two.

Hard spelling rules (fixed for the whole course — never vary):

| Write | Never | Note |
|---|---|---|
| `as` | ass | equative/relativizer particle |
| `zeele` / `zeel` | zelle / zell | future auxiliary, per Louden |
| `browiere` | probiere, browiera | 'try' |
| `iewe` | üben, ieva | 'practise', BBB rendering of /iːwə/ |
| `bsinne` | besinne | 'remember' (reflexive) |
| `Watt` | Wort | 'word' |
| `meeglich` | möglich, meiglich | 'possible' |
| `uff` | auf | 'on / in (a language)' |
| `heit`, `hatt`, `nau`, `net`, `ebbes`, `eb` | heute, hart, jetzt, nicht, etwas, ob | see leakage checklist |

Rule of thumb: if a draft word looks like Standard German spelling (umlauts, `au` where PD has `aa`, `-tz-` where PD has `-ss-`, etc.), it is wrong until verified against Beam/padutchdictionary.

## Divergence from parent (German → PA Dutch)

PA Dutch is Palatine German restructured by 300 years of isolation + English contact. **Standard German intuition is the #1 source of errors.** What transfers vs what must be re-derived:

**Transfers (safe):** V2 main-clause order; verb-final subordinate clauses; three genders + der/die/es articles; perfect tense with hawwe/sei; separable prefixes; basic case concept (nom/acc/dat).

**Does NOT transfer (re-derive every time):**

| Standard German | PA Dutch | 
|---|---|
| sprechen | **schwetze** |
| nicht | **net** |
| jetzt | **nau** (English loan) |
| wir | **mir** |
| das (article/pron.) | **es** / **sell** (demonstrative) |
| etwas | **ebbes** |
| ob | **eb** |
| so X **wie** Y | so X **as** Y |
| simple past (ging, sagte…) | **does not exist** — perfect only; sole preterite survivor = `war` |
| genitive | **does not exist** — `em Mann sei Haus` / `vun` |
| würde | **deet** (duh-conditional) |
| werden-future | **zeele + bare infinitive** |
| zu-infinitive (zu lernen) | **NO zu.** Either `fer` + inf or bare inf (rules below) |
| plain present for ongoing action | **obligatory am-progressive**: `Ich bin am schwetze` |
| Satz 'sentence' | **TRAP: PD Satz = yeast/coffee-grounds.** 'sentence' = English loan **Sentence** (treated fem., pending native check) |

Any `zu`-infinitive, `nicht`, `wie`-equative, genitive, or preterite in a draft = leakage. Delete and re-derive.

## Core grammar the builder needs

**Present tense** (only finite tense besides `war`): `ich schwetz / du schwetzscht / er-sie-es schwetzt / mir-dir-sie schwetze`. Key irregulars: `sei`: bin, bischt, is, sin. `hawwe`: hab, hoscht, hot, hen. `wolle`: **ich will, du witt** (2sg — lemma wolle vs welle is an open item, but these finite forms are fixed), er will, mir welle. `kenne` 'can': kann, kannscht, kann, kenne. `zeele` 'will/plan to': ich zeel, du zeelscht…

**Past:** perfect only — `Ich hab gschwetzt`, `Ich bin gange`. Sole simple past: `war`. Never draft another preterite.

**Future:** `zeele + bare infinitive` (Lancaster; `figgere` is the Midwestern rival — do not use). `Ich zeel … lanne.`

**Progressive (obligatory):** every English progressive prompt = `sei + am + infinitive`: `Ich bin am browiere`. A non-progressive rendering of "I'm trying / I'm going" is an **error**, not a style choice.

**Conditional:** `deet + infinitive` (never würde).

**Infinitive marking — the fer rule (Louden, verbatim logic):** `fer` appears **only** where English *requires* a to-infinitive with no gerund alternative (purpose clauses: `fer browiere ausfinne wer…`; `the first fer…`). If English requires or *permits* a gerund or bare infinitive ("try learning", "like speaking"), **no marker at all**. Never after modals (will/kann/muss/zeel). Never after `browiere` or `gleiche`. `zu` never.

**Word order:** V2 in main clauses; verb-final in subordinate clauses (`eb ich … bsinne kann`; `was ich meen`). **Verb clusters:** infinitival clusters run **head-first** (`zeel browiere auslege`, attested `browiere ausfinne`); participial clusters run **dependent-first** (`ausgebutzt griege`). Both orders are correct in their own class — do not "harmonize" them. Wh-/dass-clauses extrapose after the cluster: `Ich zeel browiere auslege, was ich meen.`

**Cases:** nom/acc/dat; **no genitive**. Course policy (BBB literary norm): dative retained after `mit` → `mit dir` (native-check item #3; whatever the native decides propagates to every preposition seed). `uff` + acc in the bsinne construction (a guess — see gotcha 10).

**Adjective endings:** weak position (after der/die/es) = **ENDINGLESS**: `die ganz Woch`, `uff der alt Bauerei`. Strong `-i` only after `en/'n` or bare: `en gudi Fraa`, `'n first-rate-i Chance`. Adding -i after die (`die ganzi`) is a proven hypercorrection trap.

**Reflexives:** `sich bsinne` 'remember' is reflexive: `ich … mich … bsinne`, `du … dich … bsinne`.

**Generic 'one/you':** `mer` (`wie mer … saagt`).

| # | Known | Target | Note |
|---|---|---|---|
| 1 | I'm not sure | 🔒 `Ich bin net sicher` | sealed formula |

## Gotchas

1. **browiere is modal-like: BARE infinitive.** `browiere ausfinne`, `browiert, net zu viel denke` — never `browiere fer + inf`. Pass 1 wrongly standardized fer here; expect reviewers to re-insert it. Correct: `Ich bin am browiere lanne.`
2. **fer rule:** fer only where English requires a to-infinitive with no gerund alternative (purpose clauses). Never after will/kann/muss/zeel/browiere/gleiche. Any `zu`-infinitive = Standard German/Palatine leakage.
3. **Adjective endings:** after der/die/es = endingless (`die ganz Woch`); `-i` only after en/'n or bare (`en gudi Fraa`). `die ganzi` is a hypercorrection — it actually happened in pass 1.
4. **Leakage checklist:** schwetze/net/nau/mir/ebbes/eb; `so X as Y`; no simple past (only `war`); no genitive; deet not würde; zeele-future never werden.
5. **Satz trap:** PD `Satz` = yeast/coffee-grounds. 'sentence' = `Sentence` (fem., pending confirmation).
6. **Obligatory am-progressive:** English progressive → `sei + am + inf`, always. Non-progressive rendering = error.
7. **Spelling discipline:** BBB Lancaster only; fixed forms `as, zeele/zeel, browiere, iewe, bsinne, Watt, meeglich`. Never mix rival spellings.
8. **Case policy:** `mit dir` (BBB dative) until the native check rules; the answer silently infects every later preposition seed — apply it course-wide the day it lands.
9. **Corpus caution:** Hiwwe wie Driwwe mixes European Palatine writers with PD writers — zu-infinitives and Palatinisms there are NOT PD evidence. Reliable anchors: Louden, Beam, padutchdictionary.com.
10. **bsinne:** reflexive is confirmed; the `uff` government is an unattested guess shared by seeds 6 and 10 — one bet, fix together. Natives may prefer bare `bsinne` + clause (restructures both).
11. **Cluster order is class-dependent:** infinitival = head-first (`browiere ausfinne`), participial = dependent-first (`ausgebutzt griege`). Don't let anyone "fix" one to match the other.

## Instructions to Opus for continuing (seeds 11+)

1. **Translate against the contracts, not against German.** For every new canonical seed: first map each English chunk to an existing ZUT contract above. If a contract exists, you MUST reuse it verbatim (same lemma, same spelling, same construction). Only chunks with no contract get new research.
2. **New-word workflow:** check padutchdictionary.com / Beam / Louden for the PD lemma; take the BBB spelling; run it through the leakage checklist (§Divergence) before accepting. If your only source is Standard German intuition or Hiwwe wie Driwwe, the word is **unverified** — see rule 5.
3. **New constructions:** apply the grammar section mechanically — am-progressive for every English progressive, zeele-future, perfect-only past, fer-rule for infinitives, verb-final subordinates, head-first infinitival clusters, endingless weak adjectives. When two rules seem to conflict, re-read the relevant gotcha before improvising.
4. **Reuse the decomposition patterns:** am-progressive sealed as one chunk; bare infinitives as standalone reusable atoms (they recur after modals/zeele/browiere identically); subordinate clauses sealed; reflexive-verb frames sealed with a slot. New reflexive or particle verbs get the seed-10 frame treatment.
5. **Flag, don't invent.** PA Dutch is thin online; expect no attestation for many things. Confidence protocol:
   - **High:** attested form/construction in Beam/Louden/padutchdictionary, or direct reuse of a locked contract.
   - **Medium:** derived by rule from the grammar section, no direct attestation → ship in draft, add a numbered native-check question.
   - **Low / defer:** preposition government, complement type of a new verb (fer vs bare vs clause), gender of English loans, idioms, anything emotional/idiomatic ("I'd love to", "never mind") → do NOT guess a form and build phrases on it. Draft one candidate, mark `confidence: low`, add it to the native-check list, and if it would become a load-bearing template for later seeds, HOLD those seeds until the native answers. The bsinne-uff situation (one unverifiable guess silently shared by two seeds) is the failure mode to avoid: never let a low-confidence bet spread to a third seed unflagged.
6. **Keep the native-check list alive.** Every new open bet gets appended, numbered, with the exact seeds it governs — the list is the contract between you and the native session. When a native ruling lands, apply it course-wide the same day (grep the whole course, not just the flagged seeds).
7. **Never** re-open the locked gotchas (fer after browiere, ganzi, wie-equative, Satz) no matter how plausible a "fix" looks — each one was already made and reverted once. If a reviewer proposes one, the answer is in §Gotchas.
