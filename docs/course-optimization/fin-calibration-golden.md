# fin_for_eng — golden calibration (seeds 1–10)

Working doc for the interactive calibration with Kai (2026-07-14). Agreed decompositions become the canonical "Approved Calibration Seeds — YOUR Quality Reference" injected into the Opus build brief. BUILD/USE phrases added after decomposition is locked per seed.

Register: colloquial spoken (mä/sä/se/ne, haluun, oon). Frozen mapping + §4 decomp rules from `fin-general-issues-status.md` apply.

## Formatting rules for LEGO content
- LEGO known and target text is **pristine**: no ellipses, no parentheticals, no slashes.
- Component lists name the real sub-LEGOs only (e.g. `usein, mahdollista`) — connective words like `niin`/`kuin` are simply part of the composite target, not a described "frame".

## Standing decisions
- **Finnish → `suomea`** (A-LEGO). No `suomi` nominative in course. `suomeksi` = separate "in Finnish" LEGO. `Suomen oppiminen` (S0064) = separate genitive-nominalization chunk.
- **how → `miten`** (manner). "how" plus a gradable word — much, long, many, old, quickly, high — is `kuinka` + that word, taught as its own LEGO. Different English marker, ZUT-safe. Later: "how much" wobbles `kuinka paljon` vs `paljonko` — resolve at S0076, S0245, S0569, S0570.
- **what → `mitä`** (object; also a usable standalone "What?"). Copular "what X is" → `mikä`, chunked in-frame later so bare "what" never resolves to `mikä`.
- **hard → `kovasti`** (effort). Difficulty sense → `vaikea`, chunked in-frame (S0526 "hard to believe" → `vaikea uskoa`).
- **Granular-first ordering**: debut a reusable piece as its own A-LEGO before the composite M-LEGO, even when early practice is thin — a scary composite should be seen in pieces first, not dumped whole this early.
- **High-variation inflected verbs stay ABSORBED** — never a piece or component. `pystyä`/`pystyn` (able to): glossed as infinitive the learner can't map to `pystyn`; glossed `pystyn` they can't remember or generalize it. Keep inside the whole chunk.
- **Infinitive gloss carries "to"**: `to speak`→`puhua`, `to practise`→`harjoitella`. "to" overlapping across LEGOs is fine.
- **Phrase caution**: never generate a BUILD/USE phrase that would mislead the learner about a mapping (esp. the plain-verb pattern in S0010).

## BUILD / USE phrases (cumulative vocab; max valid combos, fragments-if-grammatical, no dups)

**BUILD = short debut connection** — 2-LEGO combos (subject OK: `I want to speak → mä haluun puhua`) and grammatical fragments of any length. **USE = the longer 3+ LEGO phrases** (guideline, not hard rule) — the ones that stay challenging when they resurface later in spaced repetition. A LEGO whose only combinations are 2-LEGO is BUILD-only this early; its USE deepens as vocab accumulates. A LEGO with nothing prior to combine with skips BUILD (course's first LEGO; standalone clause-opener like `I'm not sure`).

**MAXIMISE combinations — every valid one with the accumulated pool, not a sample.** A verb LEGO takes every prior object/adverb/embedded-clause it grammatically can (`muistanko mä` → + sanan / jotain / koko lauseen / nyt / tänään / usein / mitä mä tarkoitan / miten sanoa jotain / jotain suomeksi …). Later seeds have a large pool, so their lists should be long. Only bar: grammaticality and no misleading mapping. The lists below are the intended density, not a floor.
